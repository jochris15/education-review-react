# Review React

## Setup
```js
npm create vite@latest
cd my-project

npm install
npm run dev
```
<br>

[Dokumentasi setup react vite](https://vitejs.dev/guide/)
<br>

[Dokumentasi setup router](https://reactrouter.com/en/main/start/tutorial)

## Features
- Login
- Logout
- Fetch Movies @Home
- Search + Pagination
- Add Movie
- Fetch Detail Movies @Detail
- Delete Movie
- Patch Image
- Add Movie (with reusable form)
- Edit Movie (with reusable form)
- Reusable Button
